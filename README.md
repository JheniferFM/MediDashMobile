


          
# Telas do Projeto (MediDash Mobile)




          
Intuito do projeto (MediDash Mobile)

- O MediDash Mobile foi criado para facilitar a organização do uso de medicamentos e evoluir para uma experiência completa de acompanhamento, com dashboards que ajudem você a entender sua rotina, adesão e próximos passos.
- Além do cadastro e listagem, o objetivo é oferecer uma visão analítica simples, prática e visual, para apoiar a tomada de decisão no dia a dia.

O que já existe hoje
- Login e navegação por telas (Home, Listar Medicamentos, Cadastro/Editar).
- Cadastro/edição de medicamentos, marcação como “tomado” e exclusão.
- Comunicação entre telas via parâmetros (novo/editado) e estado em memória.

Dashboards planejados
- Resumo do dia/semana: cards com total de medicamentos programados, concluídos e pendentes.
- Adesão: percentual de medicamentos “tomados” por período, com tendência ao longo do tempo.
- Próximos horários: lista de doses a vencer, com destaque para atrasos.
- Alertas: doses atrasadas e medicamentos com baixa adesão.
- Histórico e filtros: visualização por data/medicamento, com filtragem por período.
- Visual: gráficos e indicadores simples, com cores de fácil interpretação (ex.: verde concluído, vermelho pendente).

Tecnologias
- Expo (React Native + Expo Router) e TypeScript.
- Ícones com Ionicons.
- Seletor de horário com DateTimePicker.
- Para dashboards, serão usadas bibliotecas de gráficos compatíveis com React Native (planejado).

Próximos passos para viabilizar as dashboards
- Persistência local (AsyncStorage) e/ou backend com API para salvar histórico e métricas.
- Cálculo de estatísticas (adesão, pendências, atrasos) e geração de séries temporais.
- Notificações (lembretes) para melhorar a adesão.
- Exportação/compartilhamento de relatórios (CSV/PDF).
- Melhorias de UX e acessibilidade, com filtros e visualização responsiva.

Valor para você
- Centralizar informações de medicamentos em um só lugar.
- Visualizar progresso, pendências e próximos horários de forma clara.
- Acompanhar sua adesão e identificar oportunidades de melhoria com dados simples e úteis.
